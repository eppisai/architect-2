# Custom interface artwork

Created for Architect 2.0 with the built-in image-generation tool on 28 September 2026 under the user’s request for custom graphics and transparent icons.

- knowledge-cover.webp: reference handbook; answer questions.
- triage-cover.webp: correspondence trays; route requests.
- insight-cover.webp: plotting sheets and data bars; explain numbers.
- create-icon.webp: architectural paper construction; create an app. Transparent alpha.
- import-icon.webp: project folder; import a project. Transparent alpha.

Direction: tactile ivory paper, graphite and muted eucalyptus green; soft natural light; calm editorial still life. No readable text or brands. These are conceptual covers, not generated-app screenshots. Covers are 900×600; icons are 256×256. WebP encoding retains alpha. Full-resolution originals remain in the generation session.
